### Nepal Air Quality Analysis

An interactive data-science project analysing Nepal's estimated annual **PM2.5 exposure from 1990 to 2023** using World Bank data.

**Built with:**

`Python` · `Pandas` · `Plotly` · `Streamlit` · `Jupyter`

**Project highlights:**

- Cleaned and prepared historical air-quality data
- Analysed long-term PM2.5 exposure trends
- Created interactive data visualisations
- Developed a live Streamlit dashboard
- Documented the methodology and findings
